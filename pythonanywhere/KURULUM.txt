   - "mysite" klasörüne gir (yoksa oluştur)

3. WEB APP OLUŞTUR
   - "Web" sekmesine git
   - "Add a new web app" tıkla
   - "Flask" seç
   - Python 3.10 seç
   - Path olarak: /home/KULLANICIADIN/mysite/app.py yaz

4. ŞİFRE DEĞİŞTİR (ÖNEMLİ!)
   - Files > mysite > app.py dosyasını aç
   - Satır 15-16'daki şifreyi değiştir:
     API_USERNAME = "santiye"
     API_PASSWORD = "2024"  # KENDİ ŞİFRENİ YAZ!

5. ÇALIŞTIR
   - Web sekmesinde yeşil "Reload" butonuna tıkla
   - Adresin: https://KULLANICIADIN.pythonanywhere.com

6. TELEFONA EKLE

   - Adresi gir: https://KULLANICIADIN.pythonanywhere.com
